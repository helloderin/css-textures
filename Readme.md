# css-textures

A zero-dependency CSS texture library. No images, no network requests.

## Repo structure

```
packages/
  css-textures/   — the published npm package
apps/
  playground/     — React app for previewing and developing textures
```

## Getting started

```bash
npm install
```

Then:

| Command         | Description                                        |
| --------------- | -------------------------------------------------- |
| `npm run build` | Build the package to `packages/css-textures/dist/` |
| `npm run dev`   | Start the playground                               |

## Package

`css-textures` is available on npm. See [`packages/css-textures/README.md`](packages/css-textures/README.md) for installation and usage docs.
